# 肩背计划 · 宿舍执行版

手机网址：https://shoulder-waist-dorm-plan.erburenwang.chatgpt.site

固定首餐10:30、午餐13:30、加餐16:30、晚餐19:00；可在设置修改。饮食不含米饭、花生、香菜，只需一个小煮锅，采购安排周一4天、周五3天。周一/五晚餐用当天采购的西兰花与胡萝卜；其他天用完整番茄，无合适存放条件可切换单餐常温番茄罐头。

## 使用

- 今日：实测体重、步数、快走、睡眠与当天执行状态。
- 饮食：输入实际克数，或吃完一餐后按计划量记录，实时计算参考营养。
- 训练：12周四练，按胸肩、背腹、休息、胸背、休息、肩腹＋少量腿、休息循环；逐组记录重量、实际次数、选填余力，手动确认完成。实时显示每动作和整次完成率、实际次数、负荷指数与次数达标率；跳过不计完成。首次确认或跳过后锁定本次计划分母。
- 训练实况：记录跳过原因、动作备注、实际时长、费力程度和训练感受；结束本次训练保留实际完成率，可继续补录。开始前可切换四练与组数预览完整记录界面，预览不产生实际数据。
- 动作教学：12个动作各有器械识别、起止姿势辅助图、调节说明、3条要领、2条常见错误及重量记录口径。5个匹配动作提供本地真人视频，其他7项明确提供辅助示意和专业教程链接；未开始或暂停时仍可学习。逐素材来源与许可见 `dist/assets/exercise-sources.json`。
- 训练辅助：已完成组可一键开始60/90/120秒休息计时，暂停计划时同步暂停；计时不改变实际训练量。自然周汇总实际练过次数、全部组完成次数、组完成率与累计次数，可按日期查看原始记录。
- 离线版内嵌静态教学图片；真人视频及外部专业教程需联网。教学与计时状态独立于JSON训练备份，原有备份继续兼容。
- 趋势：7天体重填满才计算均值；腰围同日两次取平均。没有虚构示例数据。
- 采购：精确分成两批，用量、可食重、估计采购毛重和单包数分别显示。

记录自动保存在当前浏览器，没有云同步。电脑和手机记录独立；定期在设置导出JSON，换设备时导入。导入前先备份，导入会替换该设备原有记录。网站访问范围沿用当前设置。

预计2026-10-21前后开始，默认尚未启动。点击开始才以当天为第1天，不限星期；暂停会冻结进度，继续后从同一个计划日接着练。既有体重、食量和训练记录始终保留在实际日期，备份包含开始与暂停状态。每周期力量4次，腿仅1次5组，腹肌3次6组；适应后每周48个正式组。

每100g营养是参考假设，按实际包装标签校正；含汁整罐与沥干肉重不能混算。鸡胸和奶必须明确标注可未开封常温保存，开一餐吃一餐；不储存室温剩饭熟菜。食品安全来源见网页饮食页。

## 本地查看

无构建依赖。使用Python在此目录启动：

```
python -m http.server 4173 --directory dist
```

浏览器访问 http://127.0.0.1:4173/ 。正式手机使用上面的HTTPS网址。
