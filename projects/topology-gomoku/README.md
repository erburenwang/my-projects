# 拓扑五子棋

一款本地运行的中文五子棋网页，提供平面、圆柱、环面、莫比乌斯环、克莱因瓶、实射影平面和球面七种棋盘拓扑。

## 运行

```powershell
npm install
npm run dev
```

构建静态页面：

```powershell
npm run build
npm run preview
```

构建产物位于 `dist/`。页面和 Rapfi WASM 均从本地资源加载，运行时不需要 CDN。

## 棋力来源

- 平面自由五子棋：本地 Rapfi WASM + freestyle NNUE 权重，运行日志确认模型加载成功后才启用。
- 其他拓扑：拓扑原生 Worker 搜索，使用该棋盘真实的五连窗口，包含立即胜/必挡预检、双重威胁判断、迭代加深 alpha-beta/PVS、置换表和强制威胁延伸。
- 若 Rapfi 无法加载，界面会明确提示并显示拓扑搜索回退状态。回退棋力不等同 Rapfi。

Rapfi 来源、版本与许可证见 `public/rapfi/THIRD-PARTY-NOTICES.md`。

“最高”难度默认可选。拓扑引擎保证先落立即胜点，并挡住唯一的一手必败点；对方已有多个不同的立即胜点时，会标记为无法单步防守。它不保证击败完美棋手，也没有宣称达到 Rapfi 棋力。

## 棋力对照

运行 `npm run benchmark:topology-ai` 可复现固定种子成对对局。参数支持 `--difficulty=casual|standard|strong|max`、`--budget-ms`、`--pairs` 和 `--output`。报告包含双方先后手胜和负、节点/秒、中位完成深度、时间与节点预算终止率及逐局记录。

当前完整最高档对照保存在 `reports/topology-ai-max-benchmark-144.json`：每种曲面使用 12 个固定开局并交换先后手，共 144 局；新引擎每手 300 ms，对照升级前保存的旧拓扑搜索。结果为 **142 胜、2 和、0 负**；圆柱 22 胜 2 和，其余五种拓扑各 24 胜，黑白先后手胜场各 71。报告显示节点上限 750,000 次/手，144 局中未触发节点上限。这支持新引擎在这组固定开局、300 ms 预算下胜过旧版本，不证明达到 Rapfi 水平。`reports/topology-ai-max-benchmark.json` 保留更早的 24 局小样本结果，生成时节点上限为 600,000 次/手，节点上限终止率为 0。

最高难度默认使用 5 秒或 75 万搜索节点上限，以先到者为准；较低难度也各自有更小的节点上限。`reports/topology-search-depth.json` 用相同的固定 8 手局面单独记录六种拓扑在最高档、5 秒预算下的搜索深度与节点数；它是搜索预算诊断，不是棋力测量。旧报告 `reports/topology-ai-benchmark.json` 是此前版本在 30 ms 下的 144 局结果（131 胜、5 和、8 负），保留作历史对照。Rapfi parity 仍未测量：没有找到 Rapfi 对这些接缝规则的兼容证据，平面 Rapfi 结果不能替代同拓扑对局。页面显示本次搜索实际完成深度和预算终止原因。

`reports/planar-rapfi-control.json` 保存了一个浏览器实机平面控制样本：Rapfi 加载后完成合法落子，第二次搜索报告深度 17、72,950 节点、约 2.8 秒。样本只有一个局部棋谱，不是胜率测量，也不能证明拓扑棋力等同 Rapfi。

另有一个离线 249 特征、64 隐藏单元评估器实验：`reports/topology-ai-model-benchmark.json` 记录了它与同一搜索的窗口特征评估器进行 144 局对照，模型为 16 胜、11 和、117 负；隔离验证集 MSE 从 1.0011 上升到 1.0202。因此它只保留为实验产物，不进入默认对局，也不放进公开模型目录。

可用以下命令重新生成离线训练数据并训练候选模型：

```powershell
npm run data:topology-ai -- --games-per-topology=24 --budget-ms=12 --seed=20261017
npm run train:topology-ai -- --epochs=12 --seed=20261018
```

训练样本按开局种子切分，训练脚本会拒绝同一开局同时进入训练集和验证集。候选模型默认写入 `work/`，不会自动接入页面；只有在验证集和成对对局都不退步后才适合启用。

## 离散曲面约定

各旅程使用各自的格点尺寸：方庭 15×15、回廊 7×6、环游 7×6、扭带 8×6、瓶界 7×6、双生 8×8、归圆 7×7。球面与实射影平面的两极汇聚为单点；实射影平面进一步把对跖点识别为同一格点。归圆使用 7 条经度线，跨极时按最接近半周的整数列偏移连接；双生的 8 列可精确两两对跖。平面默认棋盘仍为 15×15。

二维棋谱使用展开图；三维图显示曲面示意并支持拖动旋转、滚轮缩放。克莱因瓶和实射影平面在三维中的交叉/识别关系是示意模型，落子和胜负始终由共享的离散拓扑数据决定。

## GitHub 资源打包

完整 Rapfi 权重按分片保存在 `engine-data/`。`npm install`、`npm run dev` 和 `npm run build` 会自动合并并验证 SHA-256，无需联网下载权重。原应用与第三方许可保持不变。
